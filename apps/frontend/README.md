# AI Interviewer Frontend

The frontend application for the AI Interviewer, built with React, Bun, Tailwind CSS, and Shadcn UI components.

## Features

- **Personalized Interview Form**: Upload resume, LinkedIn PDF, and provide GitHub details.
- **Voice Interface**: Interactive, real-time audio conversation interface for the technical interview.
- **Assessment Review**: Clean UI to view feedback, score breakdown, and suggested improvements.

## Getting Started

### Installation

Ensure the root dependencies are installed:
```bash
bun install
```

### Running the App

To start the frontend development server:
```bash
bun dev
```

The application will run locally. Make sure the backend application is running concurrently to handle the API requests and WebSocket voice connection.
